# php-demo

Koleksyon ng mga PHP lab exercises.

## Mga Files
- `index.php` - Main page
- `lab1.php` - Lab 1
- `lab2.php` - Lab 2
- `lab3.php` - Lab 3

## Paano patakbuhin
1. I-install ang PHP o XAMPP.
2. I-clone ang repo:
   `git clone https://github.com/raebencamarce-hash/php-demo.git`
3. Pumunta sa folder: `cd php-demo`
4. Patakbuhin: `php -S localhost:8000`
5. Buksan sa browser: http://localhost:8000
